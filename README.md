# Schattenlauf

Plane die Verschattung von PV-Modulen in 3D. Die App zeigt Sonnenstand, Schattenwurf und Tagesverlauf für einen frei wählbaren Standort und rechnet eine Jahresanalyse der Verschattung.

## Nutzung

Öffne `index.html` im Browser. Die App ist eine einzelne HTML-Datei und lädt three.js r128 von cdnjs.cloudflare.com. Projekte werden lokal im Browser gespeichert.

## Funktionen

- Gebäude, Bäume und PV-Module platzieren und bearbeiten
- Sonnenbahn, Schattenwurf und PV-Leistung im Tagesverlauf
- Jahresanalyse mit Heatmap und Projektvergleich
- Import von LoD2-Gebäuden aus CityGML-Dateien (Geobasis NRW)
- Luftbild als Bodenfläche ausrichten

Die Berechnung nutzt ein Klarhimmel-Modell. Für Ertragsprognosen mit Wetterdaten eignet sich PVGIS der EU-Kommission.
